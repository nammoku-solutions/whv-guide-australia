## 投稿・更新時の基準

1. 事前準備には「全員に必要」と「条件に応じて必要」を区別して書く。
2. 各手順に、開く窓口、入力・添付する情報、保存すべき控え、次に進む条件を書く。公式サイトのトップではなく、可能な限り対応する申請や案内へ直接リンクする。
3. 申請受付と許可、登録とアカウント有効化、請求と入金を区別する。提出を自サイトで受け付ける必要はない。
4. 日付や料率を変更するときは同じ事実を載せる他記事も検索し、実施日・対象者・例外を確認する。
5. `npm run validate:articles`、`npm run validate:content`、`npm run test:procedures`を実行する。
